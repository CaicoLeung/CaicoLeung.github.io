# Dragonfly 主 App · 产品化设计（v2）

设计对象：主 App（容器 App）。键盘扩展不在本次范围，只在文案里被说明。
预览：`design/host-app/index.html`（单文件，`python3 -m http.server 8787` 后访问 `http://localhost:8787/`）。

v2 相对 v1 的变化：
1. 首页改为四个 Tab：键盘 / 方案包 / 个性化 / 关于。
2. 输入类型、辅助码、语法模型、语法排序、模糊音、简繁、联想词全部收进「方案包详情」，与选包不在同一层。
3. 方案包列表按类别分组，列出常用开源方案（已有 2 个，未上架 14 个），首启改为「推荐一个 + 选择器」。
4. 素翼 / 夜航 / 晨光三套主题成为用户可选的外观主题；App 图标可随主题或单独选。
5. 新增「部署状态」卡（引擎 / 在役包 / 上次部署 / 进行中的任务）。

术语沿用 `GLOSSARY.md`。状态口径：**已实现** = 行为与设置项都已落地；**开发中** = 设置项尚未提供，部分底层行为可能已存在。预览里「开发中」项一律不响应，只有外观主题与 App 图标例外（为便于对比，预览里可直接切换，并标明）。

## 二、UX 设计说明

### 2.1 信息架构

四个 Tab，各自独立栈；Tab 内最多再下两层。

```
首启引导（全屏 cover，无滑返）
└─ 1 选布局 → 2 推荐配置（含方案包选择器）→ 3 装包 → 收起到「键盘」Tab

Tab 键盘
├─ 状态行（在役包 · 输入类型 · 引擎）／ 编译中 ／ 未装包横幅
├─ 试打（卡片，点开才出输入框）
├─ 键盘布局（大卡） → 二级：布局 / 默认键盘 / 键盘高度 / 键序预设
├─ 候选栏（大卡）   → 二级
├─ 按键与手势（大卡）→ 二级
├─ 标点与符号（大卡）→ 二级
└─ 剪贴板（列表项） → 二级（整页开发中）

Tab 方案包
├─ 部署状态卡（引擎 / 在役包 / 上次部署 / 进行中任务）
├─ 在役包卡 → 二级：方案包详情
│     ├─ 状态：包 / 版本 / 状态 / 许可 / 在役天数
│     ├─ 输入类型（单选；万象切换 = 确认 → 编译）
│     ├─ 语法：语法模型 / 语法排序 / 删除（仅引用语法模型的包）
│     ├─ 方案设置：辅助码 / 模糊音 / 简繁 / 联想词
│     └─ 管理：检查版本 / 查看许可全文 → 三级：许可全文
└─ 全部方案包（分类列表）→ 未下载：许可 sheet → 安装；已下载：点按秒切；未上架：开发中提示

Tab 个性化
├─ 外观主题（三选，即时切换）
├─ 主 App 深色模式 / 键盘主题（开发中）
├─ App 图标 → 二级：四个图标
└─ 统计看板 → 二级

Tab 关于
├─ 简介 / 版本 / 引擎 / 在役包（→ 方案包详情）
├─ 数据与隐私 → 二级 → 三级：隐私说明
└─ 许可全文（三级）/ 开源致谢 / 反馈 / 重看首启引导
```

为什么这样分：键盘 Tab 回答「怎么打」，方案包 Tab 回答「用什么打」，个性化 Tab 回答「长什么样」，关于 Tab 回答「这是什么、我的数据在哪」。输入类型和语法模型随包走，所以放进方案包详情，不再与选包并列。

试打区放「键盘」Tab 顶部，收成一张卡，点开才出输入框。理由同 v1：换包、切输入类型、改布局后要马上验证；输入框常驻会一进来就弹键盘。

### 2.2 首启分流流程

```
启动 → 无在役包？ → 全屏首启引导
  步骤 1 选布局：[二十六键] [九宫格 ‹开发中›]
     选九宫格 → 常驻提示「九宫格开发中，键盘当前仍按二十六键运行」→ 步骤 2 只列通用项 + 九宫格预告项
  步骤 2 推荐配置
     方案包 行：默认 雾凇拼音，「›」打开选择器
        选择器（底部 sheet）：推荐（雾凇 / 万象）· 拼音 · 双拼 · 形码 · 方言与其他
        已上架的点了即选；未上架的标「开发中」→ 统一提示
     输入类型 全拼 · 触感反馈 关 ‹需允许完全访问› · （万象）随包安装语法模型
     一句说明为什么要装包
     [开始装包 · 约 47 MB]
  步骤 3 装包：预检 → 许可确认 → 蜂窝二次确认 → 六阶段进度（可取消）→ 编译（不可取消，计时）→ 自动收起
     预检不足 → 「磁盘空间不足：安装峰值约需 500 MB，当前可用 312 MB。已取消，未产生任何残留」[重试] [稍后]
  [稍后在设置中安装] → 「键盘」Tab 顶部横幅「未安装方案包，键盘目前只能打英文」[去装包]
```

### 2.3 导航、标题、安全区

- 底部 Tab 栏四项：键盘 / 方案包 / 个性化 / 关于，49 pt + 34 pt 安全区，不透明底。Tab 间切换无转场动画（只换内容），Tab 内 push 右缘滑入、可被返回手势打断。
- Tab 根页用衬线大标题，左对齐，滚动不折叠；二级页大标题滚动后折叠为居中 17 pt 半粗；三级页同。首启是全屏 cover，盖住 Tab 栏，无滑返。
- 列表底部 inset 留出 Tab 栏高度；固定按钮只在首启与 sheet 内出现，置于安全区之上。

### 2.4 状态与反馈

| 状态 | 呈现 | 位置 | 文案模板 |
|---|---|---|---|
| 下载中 | 六阶段步骤 + 进度条 + 百分比，可取消 | 方案包 Tab 部署状态卡 / 首启步骤 3 / 详情页 | 下载中 · 42% |
| 编译中 | 阶段 + 五子步骤 + 已计时，不可取消，「四翼悬停」指示；键盘 Tab 状态行变强调色 | 同上 | 正在编译词库 · 已耗时 1:24。期间键盘只能打英文。 |
| 失败 | 行内红字 + 重试，不弹窗 | 发生处 | ＜阶段＞失败：＜原因＞。已清理，未占用空间。 |
| 预检失败 | 同失败，数字给足 | 装包第一步 | 磁盘空间不足：安装峰值约需 500 MB，当前可用 312 MB。已取消，未产生任何残留。 |
| 完全访问门控 | 锁标 + 控件仍可点 → sheet 说明 | 按键与手势 / 数据与隐私 | 需在系统设置中开启「允许完全访问」才会生效。不开启不影响打字。 |
| 空态 | 淡化四翼标记 + 一句话 + 一个动作 | 剪贴板 / 统计 | 还没有内容。开启后，复制过的文字会出现在这里。 |
| 未上架 | 行尾「未上架」+「开发中」胶囊 → 统一提示 | 全部方案包 / 选择器 | 「朙月拼音」正在开发中，预计随 V1.1 提供。当前版本不会生效。 |
| 完成 | 顶部 toast 2 秒 | 全局 | 雾凇拼音已就绪，回到任何输入框即可打字。 |

### 2.5 「开发中」的统一呈现

- 胶囊角标 `开发中`，细描边、无填充；控件降到 40% 不透明度且不响应，整行可点。
- 点击 → 底部 sheet，标题为条目名，正文：「「九宫格」正在开发中，预计随 V1.1 提供。当前版本不会生效，现有打字不受影响。」单按钮「知道了」。
- 唯一例外：外观主题与 App 图标在预览里可直接切换（为了对比三套主题），卡片页脚注明「预览中可试，正式版随主题系统提供」。
- 首页摘要只显示已实现的值，开发中项以「N 项开发中」计数。

### 2.6 微文案语气

正例：
1. 「正在编译词库 · 已耗时 1:24。期间键盘只能打英文。」
2. 「磁盘空间不足：安装峰值约需 500 MB，当前可用 312 MB。已取消，未产生任何残留。」
3. 「按键触感反馈需要「允许完全访问」。不开启也能正常打字。」
4. 「已切换到万象拼音。重新弹出键盘即生效。」
5. 「朙月拼音正在开发中，预计随 V1.1 提供。当前版本不会生效。」

反例：
1. 「编译中，请稍候…」（没说多久，没说键盘会怎样）
2. 「哎呀，出错了！请重试」（情绪化，无原因）
3. 「开启完全访问以解锁全部功能！」（夸大、感叹号）
4. 「设置成功！🎉」（感叹号 + emoji）
5. 「敬请期待~」（卖萌，零信息）

规则：陈述句；一句话里给「发生了什么 + 对打字的影响」；数字带单位；不用感叹号、emoji、「敬请期待」。

### 2.7 动效

- Tab 切换无动画；push 280 ms，可中断；按压 ≤ 100 ms 缩放 0.98；开关 / 分段 160–200 ms ease-out，无弹簧。
- 「四翼悬停」1.6 s 循环只在编译中出现；Reduce Motion 时取消。
- 进度条只在有真实进度（下载）时出现；编译用步骤 + 计时。toast 只淡入淡出。

### 2.8 区块色块规则

- 色块只用于图标底块，不用于正文背景。色相固定：布局 青 185° · 方案 碧 165°（主色同族）· 手势 朱 12° · 外观 檀 350° · 标点 赭 35° · 候选 黛 225° · 统计 黛 225°；剪贴板、隐私、关于用中性色块。
- 亮色：图标 S 45–55% L 36–40%，底块 S 35–45% L 93–95%。暗色：图标 L 70–75%，底块 S 20–30% L 18–22%。
- 主色只用于导航强调、主按钮、选中态、Tab 选中；强调色只用于「在役」标记、进度、当前步骤。

### 2.9 情绪价值触点

1. 今日字数：统计页顶部大号衬线数字，无动画。
2. 在役第 N 天：在役包卡与详情页。
3. 首选命中率：「第一候选就是想要的词」的比例。
4. 编译等待的诚实计时：已耗时 + 完成后一句「词库已就绪」，不庆祝。
5. 里程碑一行字：累计 5 万字前显示「还差 1,790 字」。

预览里体现 1、2、3、4。

## 四、硬约束自检

| 约束 | 处理 | 预览落点 |
