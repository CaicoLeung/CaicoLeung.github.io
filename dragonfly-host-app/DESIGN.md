# Dragonfly 主 App · 产品化设计

设计对象：主 App（容器 App）。键盘扩展不在本次范围，只在文案里被说明。
预览：`design/host-app/index.html`（单文件，`python3 -m http.server 8787` 后访问 `http://localhost:8787/`）。

术语沿用 `GLOSSARY.md`：主 App / 方案包 / 在役包 / 输入类型 / 触感反馈 / 强度档位 / 首启引导 / 语法开关 / 预检 / 渠道 / 语法模型 / 辅助码。
状态口径：**已实现** = 行为与设置项都已落地（`app/Sources/RootView.swift`、`OnboardView.swift`、`RimeInstaller.swift`）；**开发中** = 设置项尚未提供，部分底层行为可能已存在（如简繁切换目前只能靠键盘手势）。口径写进每条说明，不对用户伪装可用。

## 二、UX 设计说明

### 2.1 信息架构

最多三层。首页 → 功能区块 → 二级页 →（必要时）三级页。无 Tab 栏：设置型 App、层级浅，Tab 会把首页四张卡切碎，也会像系统设置。

```
首启引导（全屏，独立栈，无滑返）
└─ 1 选布局 → 2 推荐配置 → 3 装包 → 首页

首页（一级）
├─ 状态行：在役包 · 输入类型 · 引擎状态（编译中 / 未装包时变形为横幅）
├─ 试打（卡片，点开才出现输入框）
├─ 键盘布局（大卡）      → 二级：布局 / 默认键盘 / 键盘高度 / 键序预设 → 三级：键序预设
├─ 输入方案（大卡）      → 二级：在役包卡 / 包列表 / 输入类型 / 语法 / 模糊音 / 简繁 / 联想词 → 三级：方案包详情 → 许可全文
├─ 按键与手势（大卡）    → 二级：触感反馈 / 按键音 / 手势预设 / 上划符号 / 变音 / 触摸板光标 / Shift 锁定 → 三级：手势预设
├─ 外观（大卡）          → 二级：主 App 深色 / 键盘主题 → 三级：主题预览
├─ 候选栏（列表项）      → 二级：显示拼音 / 候选数量 / 还原全拼
├─ 标点与符号（列表项）  → 二级
├─ 剪贴板（列表项）      → 二级（整页开发中，含空态）
├─ 统计（列表项）        → 二级：看板 / 开关 / 清除
├─ 数据与隐私（列表项）  → 二级：完全访问 / 用户词 / 持久化 / iCloud / 删除包 / 导入占位 → 三级：隐私说明
└─ 关于（列表项）        → 二级：版本 / 许可 / 致谢 / 反馈 / 重看首启引导 → 三级：许可全文、开源致谢
```

首页四张大卡 = 个性化的四个维度（布局、方案、手感、外观），也是「四翼」母题的落点；其余区块是列表项，色块更小。这样一眼能分出「可玩的」和「查一下的」。

**试打区放首页，但收成一张卡，点开才出输入框。** 理由：换包、切输入类型、改布局之后必须马上验证，没有试打区就只能切到别的 App；但输入框常驻会让首页一打开就弹键盘、抢走焦点。

### 2.2 首启分流流程

```
启动
└─ 有在役包？ ── 是 ──→ 首页
   └─ 否 → 全屏首启引导（不能滑返，只能走完或「稍后」）
        ├─ 步骤 1 · 选布局
        │    [二十六键]  [九宫格 ‹开发中›]
        │    选九宫格 → 顶部常驻提示：「九宫格开发中，键盘当前仍按二十六键运行」
        │               → 步骤 2 只列通用项 + 九宫格预告项
        │    选二十六键 → 步骤 2 列通用项 + 26 键项
        ├─ 步骤 2 · 推荐配置（三项预选，可改）
        │    方案包 rime-ice（雾凇拼音）· 输入类型 全拼 · 触感反馈 关 ‹需允许完全访问›
        │    一句说明为什么要装包：词库不随 App 提供，安装包更小、许可更干净；装完要编译，几分钟，期间键盘只能打英文
        │    [开始装包 · 约 47 MB]
        ├─ 步骤 3 · 装包
        │    ① 预检（峰值 500 MB vs 可用）
        │         └─ 不足 → 失败态：「磁盘空间不足：安装峰值约需 500 MB，当前可用 312 MB。已取消，未产生任何残留」 [重试] [稍后]
        │    ② 许可确认（action sheet）：GPL-3.0 / CC-BY-4.0 → [同意并下载] [查看许可全文] [取消]
        │    ③ 网络：蜂窝 / 计费 → 二次确认 [继续下载（蜂窝）] [等 Wi-Fi 再下]
        │    ④ 进度（六阶段步骤列表）
        │         获取版本信息 → 下载（进度条，可取消）→ 校验文件完整性 → 解压文件 → 替换词库（几秒）
        │         → 编译词库（五子步骤 + 已耗时计时，不可取消；常驻一句「期间键盘只能打英文」）
        │         失败 → 行内原因 + [重试]；不留残留
        │    ⑤ 完成 → 自动收起 → 首页顶部 toast「雾凇拼音已就绪，回到任何输入框即可打字」
        └─ [稍后在设置中安装] → 首页横幅「未安装方案包，键盘目前只能打英文」[去装包]
           （下载开始后该按钮变为「在后台继续，先去看看」，装包不中断）
```

### 2.3 导航、标题、安全区

- 导航：单栈 push。二级页左上返回键 + 右缘滑入返回；三级页同。首启引导是全屏 cover，无滑返，只有「稍后在设置中安装」能退出。
- 页面标题：首页「蜻蜓」用衬线大标题，左对齐；二级页大标题左对齐 = 区块名，不带「设置」二字，滚动折叠后变居中 17 pt 半粗；三级页（sheet 内）居中标题 + 右侧「完成」。
- 底部安全区：列表底部 inset 34 pt，home indicator 区域不放任何可点元素；固定按钮置于安全区之上，按钮下方背景延伸到屏幕底；sheet 内同理。首页不放底栏。

### 2.4 状态与反馈

| 状态 | 呈现 | 位置 | 能否离开 | 文案模板 |
|---|---|---|---|---|
| 下载中 | 阶段列表 + 进度条 + 百分比 | 装包流程内；首页状态行同步 | 可离开，后台继续，可取消 | 下载中 · 42% |
| 编译中 | 阶段列表 + 五子步骤 + 已计时，不可取消；「四翼悬停」指示 | 同上；首页状态行变强调色 | 可离开，后台继续 | 正在编译词库 · 已耗时 1:24。期间键盘只能打英文。 |
| 失败 | 行内红字（朱），原因 + 重试，不弹窗 | 发生处 | — | ＜阶段＞失败：＜原因＞。已清理，未占用空间。 |
| 预检失败 | 同失败，数字给足 | 装包流程第一步 | — | 磁盘空间不足：安装峰值约需 500 MB，当前可用 312 MB。已取消，未产生任何残留。 |
| 完全访问门控 | 条目副文案带锁标 + 控件仍可点 → 底部 sheet 说明 | 按键与手势 / 数据与隐私 | — | 需在系统设置中开启「允许完全访问」才会生效。不开启不影响打字。 |
| 空态 | 淡化四翼标记 + 一句话 + 一个动作 | 剪贴板 / 统计 / 许可 | — | 还没有内容。开启后，复制过的文字会出现在这里。 |
| 完成 | 顶部 toast，2 秒，无庆祝动画 | 全局 | — | 雾凇拼音已就绪，回到任何输入框即可打字。 |

编译期间不给假百分比：librime 没有回调，只给步骤与计时，这是诚实的上限。

### 2.5 「开发中」的统一呈现

- 角标：`开发中` 细描边胶囊，11 pt，无填充（方向 A）；放在条目右上、控件左侧。
- 条目：控件降为 40% 不透明度且不响应；整行仍可点。
- 点击：底部 sheet，统一标题「开发中」，正文模板：「「九宫格」正在开发中，预计随 V1.1 提供。当前版本不会生效，现有打字不受影响。」单按钮「知道了」。
- 首页卡片摘要只显示已实现的值；有开发中项时在摘要尾部写「· N 项开发中」，不把开发中项算进值里。
- 布局选择例外：九宫格可选，但选中后在页面顶部常驻提示，并只显示九宫格作用域的开发中项。

### 2.6 微文案语气

正例：
1. 「正在编译词库 · 已耗时 1:24。期间键盘只能打英文。」（说清多久、键盘会怎样）
2. 「磁盘空间不足：安装峰值约需 500 MB，当前可用 312 MB。已取消，未产生任何残留。」（数字、结果、零残留）
3. 「按键触感反馈需要「允许完全访问」。不开启也能正常打字。」（门控条件 + 不威胁）
4. 「已切换到万象拼音。重新弹出键盘即生效。」（结果 + 何时生效）
5. 「九宫格正在开发中，预计随 V1.1 提供。当前版本不会生效。」（不卖关子）

反例：
1. 「编译中，请稍候…」（没说多久，没说键盘会怎样）
2. 「哎呀，出错了！请重试」（情绪化，无原因）
3. 「开启完全访问以解锁全部功能！」（夸大、感叹号，暗示不开不能用）
4. 「设置成功！🎉」（感叹号 + emoji）
5. 「敬请期待~」（卖萌，零信息）

规则：陈述句；一句话里给「发生了什么 + 对打字的影响」；数字用阿拉伯数字带单位；不用感叹号、不用 emoji、不用「敬请期待」。

### 2.7 动效

- 即时反馈（按压）：≤ 100 ms，缩放 0.98，松手回弹。
- 状态切换（开关、分段、步骤推进）：160–200 ms，ease-out，无弹簧。
- 页面转场：系统 push，右缘滑入，可被返回手势打断。
- 编译指示「四翼悬停」：1.6 s 循环，位移 1.5 pt，仅编译中出现；Reduce Motion 时取消循环，只保留静态标记。
- 进度条只在有真实进度（下载）时出现；编译用步骤 + 计时。
- 列表不加入场动画；toast 只淡入淡出。

### 2.8 区块色块规则

- 色块只用于首页区块图标底块与二级页标题旁的小图标，不用于正文背景。
- 色相固定到区块（可学习）：布局 青 185° · 方案 碧 165°（主色同族）· 手势 朱 12° · 外观 檀 350° · 标点 赭 35° · 统计 黛 225°。候选栏、剪贴板、数据与隐私、关于用中性色块。
- 亮色：图标 S 45–55% L 36–40%；底块 S 35–45% L 93–95%。暗色：图标 S 45–55% L 70–75%；底块 S 20–30% L 18–22%。
- 主色（碧）只用于导航强调、主按钮、选中态；强调色（朱）只用于「在役」标记、进度、当前步骤。朱不用于装饰。
- 四张大卡用 40 pt 色块，列表项用 30 pt 色块，靠尺寸拉开层级。

### 2.9 情绪价值触点

1. 今日字数：统计页顶部一个大号衬线数字，无动画、无徽章。
2. 在役第 N 天：输入方案页在役卡副标题「在役第 42 天 · 2026-10-13 起」。
3. 首选命中率：「第一候选就是想要的词」的比例，反映词库与自己一起变熟。
4. 编译等待的诚实计时：已耗时 + 完成后一句「词库已就绪」，不庆祝。
5. 里程碑一行字：累计 5 万字前显示「还差 1,790 字」，达成当天显示一次，不推送。

## 六、预览使用
