# Dragonfly 主 App · 产品化设计（v3）

设计对象：主 App（容器 App）。键盘扩展不在本次范围，只在文案与状态里被说明。
预览：`design/host-app/index.html`（v3，`python3 -m http.server 8787` 后访问 `http://localhost:8787/`）。
来源：v2 经 UX 设计师 / 产品经理 / Rime 专家三方评审，合并与裁决见 `review/v3-redesign.md`；v2 原文归档于 `review/DESIGN-v2.md`。决策记录 = `docs/architecture.md` D50。

v3 相对 v2 的变化：
1. 首启改 4 步：第 1 步改「你平时用什么」，第 4 步新增「启用键盘」；输入类型改真选择；语法模型默认关；跳过持久化。
2. 「输入类型」切换改预编译多 schema、秒级、无重编译；界面文案统一「输入方案」。
3. 方案包目录按包粒度重建（约 9 包、三类），删「双拼」分类与 Emoji 包；未上架折叠一行。
4. 方案包详情重排：摘要 → 输入方案 → 开关 → 语法 → 用户词典 → 关于此包；标点 / 全半角 / emoji 从键盘 Tab 迁入「开关」。
5. 键盘 Tab 顶部「试打」升级为「键盘状态卡」，四态。
6. Tab 4「关于」改「通用」；数据与隐私平铺；新增启用与管理键盘、帮助与自检、诊断导出。
7. 三套主题保留，键盘 + 主 App 同步派生；App 图标可选不做；主 App 深色跟随系统进首批。
8. 新增规则：「开发中」呈现、失败态语义色、界面用词表、可及性基线、等待期行为。

术语沿用 `GLOSSARY.md`。「排期」列是内部口径（首批 / V1.1 / 以后 / 不做），只用于规划，不进界面；界面不写版本承诺。† = 需允许完全访问。

## 一、信息架构

```
首启引导（全屏 cover，4 步；跳过持久化，最多第 2 次启动再弹）
└─ 1 你平时用什么 · 布局 → 2 推荐配置 → 3 装包 → 4 启用键盘 → 收起到「键盘」Tab

Tab 键盘
├─ 键盘状态卡（状态行 + 一击聚焦的试打输入框；未启用 / 无包 / 编译中 / 就绪）
├─ 键盘布局（大卡）→ 二级：布局 / 默认键盘 / 键盘高度 / 键序预设 / 九宫格项
├─ 候选栏（大卡）→ 二级
├─ 按键与手势（大卡）→ 二级
└─ 剪贴板与短语（列表项）→ 二级：快插短语 / 候选内短语 / 剪贴板历史†

Tab 方案包
├─ 在役卡（一行：使用中 · 引擎就绪 · 上次更新）→ 详情
│     ├─ 摘要 → 输入方案 → 开关 → 语法 → 用户词典 → 关于此包（折叠）
├─ 全部方案包（三类；可装项 + 一行折叠「更多方案」；「找某种双拼？」意图路由）
└─ 任务卡（仅有任务或失败时出现）

Tab 个性化
├─ 外观（三套主题；键盘 + 主 App 同步派生）
├─ 主 App 深色模式 / 键盘主题（二级）
└─ 输入统计† → 统计看板†

Tab 通用
├─ 数据与隐私（平铺）：完全访问 / 删除全部数据 / 隐私说明 / 占用总览
├─ 启用与管理键盘（常驻自检页）
├─ 帮助与自检 / 宿主 App 兼容性 / 反馈问题（附诊断包）
├─ 开源致谢 / 许可全文
└─ 简介 / 版本 / 使用中包 / 重看首启引导
```

为什么这样分：键盘 Tab 回答「怎么打」，方案包 Tab 回答「用什么打」，个性化 Tab 回答「长什么样」，通用 Tab 回答「这是什么、我的数据在哪、怎么修」。输入方案、开关、语法、用户词典都随包走，所以全部放进方案包详情；标点、全半角、emoji 是 schema 的 switches，不是键盘 UI 设置，因此从键盘 Tab 迁出。通用 Tab 是排障与数据的第一入口，所以「启用与管理键盘」「帮助与自检」住在这里而不是「关于」里。

Tab 内最多再下两层；首启是全屏 cover，盖住 Tab 栏，无滑返。

## 二、首启引导（4 步）

```
启动 → 无在役包且未跳过？ → 全屏首启
步骤 1 你平时用什么
   [全拼] [小鹤双拼] [自然码] [微软双拼] [搜狗双拼] [其他]
   底部一行：布局 [二十六键] [九宫格 ‹V1.1›]   ← 九宫格不可选，点按出统一说明 +「好了通知我」
   只有「下一步」
步骤 2 推荐配置（按第 1 步的答案推荐包并预选输入方案）
   方案包 行：推荐值（全拼 → 雾凇拼音；双拼 → 万象拼音）·「›」打开选择器（只列可装项，脚注「更多方案陆续上架」）
   输入方案 行：真选择器（底部 sheet 列该包支持的方案）· 所选方案进入首次部署
   按键触感反馈 关 ‹需允许完全访问›
   一句：语法模型可选（约 391 MB），装好后可在方案包详情里加装 ← 默认不装，不再出现开关
   [开始装包 · 约 47 MB]
   [稍后在设置中安装]  ← 跳过入口从这里开始出现
步骤 3 装包
   预检（磁盘 + 网络）→ 许可信息（来源 · 许可 · 查看全文）→ 蜂窝（> 150 MB 才问）
   → 3 阶段进度（下载 → 安装 → 编译词库）+ 单一计时 + 等待期规则（§五）
   预检不足 → 「空间不足，还差约 190 MB」[返回上一步] [换轻量方案] [去清理]
   等 Wi-Fi → 回步骤 2 + toast「已暂停。连上 Wi-Fi 后回来点开始装包」
步骤 4 启用键盘
   四步图：设置 › 通用 › 键盘 › 键盘 › 添加新键盘… › 蜻蜓
   [打开系统设置]（回到 App 后半屏指引补齐「通用 › 键盘 › 键盘」两级）
   回来落试打输入框：「试打一句，确认能切到蜻蜓」+「看不到蜻蜓？」排障折叠
   → 收起到「键盘」Tab；toast「词库已就绪。还没添加键盘？去设置添加」
```

规则：
- 跳过 = 持久化；提醒交键盘 Tab 常驻横幅；最多第 2 次启动再弹全屏，之后不再自动弹。
- 显示的输入方案必须等于实际生效的输入方案。
- 步骤 3 只在有进行中或失败的任务时可进入，否则回落到步骤 2。
- iOS 无公开 API 判断键盘是否已添加；以用户自报 + 试打为准。
- 首启里的「查看许可全文」必须能在 cover 内打开。

## 四、状态与反馈

| 状态 | 呈现 | 位置 | 文案模板 |
|---|---|---|---|

## 五、「开发中」的统一呈现

- 开发中项只在下个版本会交付时出现；每屏不超过 2 个，超出隐藏。
- 不显示假值：开发中的行右值留空，不写「开」「标准」。
- 界面不写版本号，承诺留 roadmap。
- 胶囊角标「开发中」：细描边、无填充、三套主题都用中性色；控件降到 40% 不透明度且不响应，整行可点 → 底部 sheet「「九宫格」正在开发中。当前版本不会生效，现有打字不受影响。」[知道了] [好了通知我]（本地通知）。
- 方案包列表只列可安装的包，未上架折叠成一行「更多方案（N 个）」；首启选择器只列可装项。
- 唯一例外：外观主题在预览里可直接切换（为了对比三套）。

## 七、动效与可及性

- Tab 切换无动画；push 280 ms，可中断；按压 ≤ 100 ms 缩放 0.98；开关 / 分段 160–200 ms ease-out，无弹簧。
- 「四翼悬停」1.6 s 循环只在编译中出现；Reduce Motion 时取消，用等宽数字 + 阶段 ✓ 作存活信号。进度条只在有真实进度（下载）时出现。
- 可及性基线：三级文字 ≥ 4.5:1，图标另设 ≥ 3:1 令牌；浅色下加深强调色，链接类小字用主色；触控目标 ≥ 44 pt；支持动态字体到 AX 版，两列大卡在辅助字号下改单列；VoiceOver：开发中行读「X，开发中，按钮」，任务卡只播报阶段变化、不播报计时器。
- 失败态用 `--danger` 语义色，不随主题变。

## 九、硬约束自检

| 约束 | 处理 | 落点 |
|---|---|---|
| 无完全访问必须完全可用 | 门控只在触感反馈、剪贴板历史、用户词持久化与同步、输入统计；文案都带「不开启也能打字」 | 按键与手势 / 用户词典 / 数据与隐私 |

| 重活有可见进度与状态 | 3 阶段 + 单一计时 + 区间 + 取消 + 等待期规则；预检 / 下载失败 / 蜂窝各有独立态 | 任务卡 / 首启步骤 3 |
| 输入方案切换曾是分钟级 | 预编译多 schema，`select_schema` 秒级；重编译只留自定义 patch 兜底 | 方案包详情 · 输入方案 |
| 无包时键盘只能打英文 | 键盘侧提示行 + 主 App 横幅 + 跳过持久化；不做兜底词库（D50） | 键盘 / 键盘 Tab |
| 自定义配置导入未实现 | V1.1 以后：从文件导入整包，不做编辑器 | 通用 / 方案包列表 |

| 用户词是 Rime 核心价值 | 用户词典卡；无 FA 时如实说明会话级 | 方案包详情 |
| 不照搬参考 App、不卡通、不 emoji、不霓虹、不玻璃 | 只借结构；配色、卡片、图标自定 | 全局 |

- `index.html`：单文件，CSS / JS 内联，系统字体栈，无外部依赖；按本文 v3 重做，状态存 localStorage（键 `dragonfly-host-app-preview-v3`）。
